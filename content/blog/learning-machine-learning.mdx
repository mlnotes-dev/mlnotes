Hello there! I'm Charan, I'm a full stack developer & designer. Welcome to my machine learning blog!

"Machine Learning" really sounds cool to me but I could never really experience it properly. I've tried machine learning before but I always feel like I'm just learning fancy terms. I always feels like I got it but after a few days, I kinda lose it all.

So, this blog is my attempt to learn machine learning and build cool stuff with it.

"But AI can do everything already. Why go through all the trouble of learning it?"

Sure, AI will help me build whatever I want but, it will only take me so far. In my experience of using AI to build web apps for the past 1+ year, AI fails to accelerate my development speed to building new features beyond a certain point. And I believe that holds true for Machine Learning as well.

Besides me enjoying the process of learning something challenging, it will give me the vocabulary and help me build the understanding I need to be able to guide AI to build ML projects I want.

I'm going to start completely from the ground up, write about everything I learn, build fun little projects along the way and share all of that with the world!

Follow along if you're interested in learning Machine Learning too!
